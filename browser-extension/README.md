# CF-Navs 浏览器书签同步扩展

这是一个 Chrome / Edge Manifest V3 扩展。它只监听浏览器中之后新增的网页书签，并将书签单向写入 CF-Navs 的“浏览器新增收藏”分类。扩展弹窗使用 CF-Navs 项目图标和卡片式连接界面；密码只用于登录，扩展仅保存会话令牌。

`icon.png` 与项目 `public/icon.png` 同源；由于浏览器加载的是独立扩展目录，扩展包必须保留这份自包含副本，用于 16/32/48/128 像素的显示配置。

## 使用方式

1. 先在 CF-Navs 管理后台的“设置 → 站点设置”开启“浏览器书签同步”。开启时会自动创建“浏览器新增收藏”分类。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择本目录。
3. 点击扩展图标，填写导航页地址、管理员账号和密码，点击“登录并开启同步”。密码只用于登录，不会保存；扩展只保存会话令牌。
4. 以后新增的网页书签会自动进入“浏览器新增收藏”。文件夹结构不会同步，也不会自动改动现有分类。
5. 需要整理时，在导航页开启排序，直接把书签拖到目标分类。

关闭后台开关后，服务端会拒绝同步请求；扩展也可以单独暂停同步。整个功能没有删除接口，不会删除或反向覆盖导航页已有书签。
