# CF-Navs v0.8.0

## 新增

- 为书签和分类提供可信设备图标副本能力：在用户明确启用的设备上保留已验证图标，普通访问可以复用本地副本。
- 支持图标副本在应用升级、旧快照恢复和页面重新打开后的兼容保留。
- 增加图标失败恢复、超时恢复和跨页面复用，减少重复下载并改善瞬时网络失败后的恢复体验。
- 补充分类图标、设备缓存设置、键盘操作和窄屏布局支持。

## 修复

- 修复书签图标偶发停留在文字兜底、编辑标题后图标丢失、旧快照恢复不完整等问题（Issue #28 相关）。
- 修复登录态切换、旧响应和跨标签退出导致首页错误显示游客视图的问题（Issue #29 相关）。
- 修复低高度窗口、窄屏和顶部导航下编辑菜单被遮挡或无法操作的问题（Issue #30 相关）。
- 修复图标代理超时、失败重试、取消恢复和副本清理边界，避免失败结果覆盖有效图标。
- 修复性能审计中首页重复图标请求超出预算的问题。

## 验证

- `npm test`：180 个测试文件，2087 项通过。
- `npm run type-check`：0 errors / 0 warnings。
- `npm run accept:prod`：40/40 通过。
- `npm run perf:audit`：10/10 通过，图标请求 259，预算 260。
- 真实浏览器完成旧 bundle 到新 bundle 的同 profile 升级、旧/新标签并存、设备副本保留、关闭清理和回滚验证。

## 已知限制

- iOS Safari、真实软键盘、真实读屏软件和报告者原 Mac 环境未由本轮自动化复测。
- Issue #28、#29、#30 的关闭仍需发布后按维护者流程结合报告者反馈处理。
