# 图标本地优先缓存 v2 需求（2026-10-17 用户确认）

1. 所有图标（书签+分类，公开+私密）尽量缓存在本地 IndexedDB；匿名访客也存本地。
2. 全局标志位 `icon_epoch`：任何图标变更（增删改、重新抓取、分类图标、公开/私密切换、导入）+1；随现有 `GET /api/data/version` 返回。
3. 冷启动、热启动、刷新、页面切换（含 visibilitychange 回前台）先取标志位：相等→全读本地，零图标请求；不等→按每个对象 icon_revision 比对，只重下变化的、删除不存在的，再写入新 epoch。本设备写操作直接回传新 epoch。
4. 登出时只清除私密条目。
5. 去掉 10 MiB / 1000 条总量上限和 LRU 淘汰（用户 2026-10-17 明确要求）。仅受浏览器配额约束；建议保留单图 512 KiB 上限、申请 navigator.storage.persist()、QuotaExceeded 时回退网络（待用户确认）。
6. 去掉可信设备开关、授权回执、设备面板、旧版迁移。服务端可见性闸门与边缘缓存保留。
